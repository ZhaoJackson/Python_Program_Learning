# 🐍 100 Days of Python - Learning Journey

Welcome to my Python learning repository! This is a comprehensive collection of projects and exercises from the **100 Days of Python** programming course. This repository tracks my progress as I learn Python from fundamentals to advanced concepts.

## 📚 About This Repository

This repository is a live documentation of my journey through Python programming. Each folder represents a day (or set of days) in the course, containing practical projects that reinforce key programming concepts. The repository is continuously updated as I progress through the course.

**Purpose:**
- 📖 Track my Python learning progress
- 💻 Practice coding skills and logic
- 🎯 Build real-world projects
- 📝 Document solutions and learnings

## 🛠️ Technologies & Tools

- **Language:** Python 3.x
- **Environment:** Jupyter Notebooks, Python Scripts
- **Libraries:** random, datetime, and other standard Python libraries

## 📂 Repository Structure

Each project folder typically contains:
- `*.py` - Main Python script(s)
- `*.ipynb` - Jupyter notebooks with learning notes and experiments
- `art.py` - ASCII art for visual enhancement (where applicable)
- `data.py` / `*_words.py` - Data files for games
- Supporting files (PDFs, flowcharts, requirements)

## 🎓 Learning Path

The projects are organized in increasing difficulty:
- **Beginner (Days 1-5):** Basic syntax, variables, data types, control flow
- **Intermediate (Days 6-12):** Functions, data structures, game logic
- **Advanced (Days 13+):** Debugging, OOP, complex applications
